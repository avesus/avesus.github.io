An FPGA Cloud for Shared Designs
June 22, 2021

An FPGA cloud can make hardware designs as deployable and reusable as software services. Brian Greenforest’s platform lets people run, share, license, and compose open or proprietary circuits while the cloud handles placement, isolation, scaling, and reconfiguration.

The same environment can host server infrastructure and replace fixed multi-FPGA deployments with plug-and-play capacity.

Fuse Circuit Design With Application Development

Digital designers gain access to full applications instead of spending every cycle on protocols and arithmetic. Software developers gain parallel, composable, reusable, dynamic, and reactive components instead of treating hardware as a remote accelerator.

Multi-tenant object capabilities can isolate customers and control sharing. Fast partial reconfiguration can move a design into available regions and reshape capacity around demand.

Create the Marketplace for Executable Hardware

Open components can spread through community reuse, while proprietary cores can earn licensing revenue. Customers can combine both inside secure systems and deploy them without owning a fixed FPGA cluster.

Brian seeks seed partners, cloud operators, FPGA vendors, and customers with painful processing bottlenecks. Fund the platform, contribute a design, or bring the workload that will show its commercial power.
