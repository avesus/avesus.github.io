Rhombitrihex Cartilage

This file runs directly from file:///. It is one local HTML file. Its JavaScript, WebGL shaders, styles, examples, editor, simulator, JSON codec, labels, and waveform probes are embedded.

Each primitive rhombus contains two equilateral triangles. Each triangle is divided at its centroid and three edge midpoints. The result is six congruent kites. Each kite has four local ports.

  • Texture packing: u=3i+k, v=2j+t, spatial kite index p=3t+k.
  • Adjacency depends on the kite site. The neighbor sees reciprocal edge 3−e.
  • CROSS is internal: it joins opposite pairs (0,2) and (1,3).
  • Non-CROSS roles broadcast one result to all four outputs.
  • Role code 0 is the editable local reconfiguration PORT.
  • MUX geometry is structural: the selector shoe is S, the two other input lanes are D0/D1, and the ring gap plus heavy branch move to the selected data input when S changes. WIRE has one paired input lane; every ordinary role has four thin broadcast outputs.
  • Each motif has six spatial kite sites derived from coordinates. The stored two-bit orientation remains one of four role rotations. For WIRE it selects the local input edge; for MUX it selects the historical permutation orientation.
  • Simulation uses exactly two state planes: read the previous plane, write the next plane, then flip them.
  • Out-of-bounds inputs are zero. There is no clamp, seam, or torus.
  • Up to eight labeled probes can record local-edge outputs.

Edit: select a role, then click or drag. Choose GND / PWR and tap a kite to toggle that kite. Select “Inspect” to inspect, label, or probe a cell. On touch screens, tap to inspect or place, drag one finger to pan, and pinch to zoom. With a mouse, use the wheel to zoom and right-drag, middle-drag, or Alt-drag to pan.

Keys: Space run/pause, . step, F fit, Ctrl/Cmd Z undo.

Saved files use format cartilage-rhombitrihex-canvas, state version 5, and topology version 1. This app rejects orthogonal textures instead of silently changing their meaning.
