Cartilage Carries One Idea From Browser To FPGA

Cartilage Core begins with a spatial-computing architecture, makes local roles, routing, ownership, and configuration visible in WebGL, expresses the hardware contract independently in SystemVerilog, checks it with Verilator, and carries a physical tile through an FPGA implementation flow.

The browser installs 36 seven-bit records into a child-owned 6x6 region: 252 payload bits followed by one apply pulse. The independent RTL uses no fabric-wide application clock; application and overlay signals remain continuous local levels while routed local edges change configuration state.

July 2026 revision 48ff6e0 joins WebGL behavior, canonical SystemVerilog checks, exact serial installation, differential checks for flattened iCE40 encoding, and a Yosys/nextpnr/icepack result for a fully edge-bonded 9x8 tile on iCE40HX8K-CT256.

The routed result contains 72 cells, 5,513 LUT4, 1,512 DFF, 6,811 of 7,680 packed logic cells, and 205 of 206 bonded user I/O under the APP/C/D perimeter interface and package-pin contract.
